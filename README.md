# Seatify: Campus Cafe Finder

Create a modern mobile-first web application prototype called "Seatify".

Concept:

Seatify is a campus cafe discovery platform that helps university students find cafes with available seats for studying, working, and hanging out. The main focus is real-time cafe occupancy, available seats, queue information, and cafe discovery.

Target users:

University students, especially students who need a comfortable place for WFC (work from cafe), studying, meetings, and group discussions.

Design direction:

Use a premium minimalist coffee aesthetic inspired by luxury cafe websites.

Visual style:

- Elegant and clean layout

- Lots of white space

- Warm coffee-inspired colors

- Beige, cream, soft brown, charcoal, and subtle green accents

- Premium typography

- Smooth animations

- Modern card-based UI

- Avoid overly corporate dashboard style

- Make it feel like a lifestyle application

Reference style:

Luxury coffee website landing page with editorial layouts, large typography, high-quality cafe photography, and minimalist sections.

Platform:

Mobile-first responsive web app.

The main experience should feel like a mobile application, but adapt beautifully on desktop.

## Important UX:

The application should NOT look like a normal food delivery app.

The feeling:

"Google Maps + cafe lifestyle + study community"

Make it aspirational for university students.

Use:

- smooth scrolling

- subtle hover effects

- micro animations

- elegant transitions

- premium visual hierarchy

Prioritize visual prototype quality over backend functionality.

Use realistic mock data.
